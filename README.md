# Sentinela — Descargas oficiales

Este repositorio aloja los archivos de descarga de **Sentinela**, el auditor de seguridad personal para Windows y macOS
de [Korelabs](https://alexkore.com). Complementa a Microsoft Defender; no lo reemplaza.

Descargá la última versión desde la sección **[Releases](https://github.com/Korelabs88/sentinela-releases/releases/latest)**.

- **Setup.exe**: instalador recomendado (Windows 10/11, 64 bits).
- **Portable.zip**: versión portable, sin instalación.
- **macOS.zip**: aplicación para Mac (Apple Silicon e Intel, macOS 12 o posterior).
- **SHA256SUMS.txt**: hashes para verificar las descargas. La app los verifica antes de actualizarse.

> El código fuente se mantiene en un repositorio privado. Acá solo se publican los binarios listos para usar.

Sitio oficial: https://alexkore.com
